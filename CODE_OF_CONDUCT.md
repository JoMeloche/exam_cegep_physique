# Code de conduite / Code of Conduct

*Adapté du [Contributor Covenant 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).
Adapted from the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).*

## Notre engagement

Nous, membres, contributeurs et responsables, nous engageons à faire de la participation à ce projet une expérience
sans harcèlement pour tous, quels que soient l'âge, la taille, le handicap visible ou invisible, l'origine ethnique,
les caractéristiques sexuelles, l'identité et l'expression de genre, le niveau d'expérience, l'éducation, le statut
socio-économique, la nationalité, l'apparence, la race, la religion ou l'orientation sexuelle.

## Nos normes

Comportements attendus :

- faire preuve d'empathie et de bienveillance ;
- respecter les opinions, points de vue et expériences différents ;
- donner et recevoir des commentaires constructifs avec élégance ;
- assumer ses erreurs, s'en excuser auprès des personnes touchées et en tirer des leçons ;
- privilégier ce qui est le mieux pour la communauté, pas seulement pour soi.

Comportements inacceptables :

- langage ou images à caractère sexuel, attention ou avances sexuelles ;
- trolling, commentaires insultants ou dénigrants, attaques personnelles ou politiques ;
- harcèlement public ou privé ;
- publication d'informations privées d'autrui sans permission explicite ;
- partage de contenu d'évaluation confidentiel (examens en cours, données d'étudiants) ;
- toute autre conduite raisonnablement considérée comme inappropriée dans un cadre professionnel.

## Application

Les responsables du projet clarifient et font respecter ces normes, et peuvent retirer, modifier ou refuser les
commentaires, commits, code, tickets et autres contributions qui ne les respectent pas.

Pour signaler un comportement inacceptable, écrivez en privé au responsable du projet,
[@JoMeloche](https://github.com/JoMeloche), par l'onglet
[Security → Report a vulnerability](https://github.com/JoMeloche/exam_cegep_physique/security/advisories/new)
(en précisant qu'il s'agit du code de conduite). Les signalements sont traités rapidement et de façon confidentielle.

Selon la gravité : avertissement privé, avertissement public, exclusion temporaire, puis exclusion permanente.

## Portée

Ce code s'applique dans tous les espaces du projet (dépôt, tickets, discussions, pull requests) et lorsqu'une
personne représente officiellement le projet.

## Our pledge (English)

We pledge to make participation in this project a harassment-free experience for everyone. Be kind and respectful,
give and accept constructive feedback, own your mistakes, and focus on what is best for the community.
Harassment, insults, personal attacks, sexualized content, publishing others' private information, and sharing
confidential assessment material (live exams, student data) are not acceptable.

Report unacceptable behavior privately to the maintainer, [@JoMeloche](https://github.com/JoMeloche), through
[Security → Report a vulnerability](https://github.com/JoMeloche/exam_cegep_physique/security/advisories/new)
(mention it is a Code of Conduct report). Reports are handled promptly and confidentially. Maintainers may remove
contributions and warn or ban participants who break these rules. This code applies in all project spaces and when
representing the project.
